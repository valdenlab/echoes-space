# Echoes in the Cosmos: Relics of Mars and the Moon

> **Challenge:** *Abandoned, but Not Forgotten*  
> **Repository:** [github.com/valdenlab/echoes-space](https://github.com/valdenlab/echoes-space)

**Echoes in the Cosmos** is an interactive, zero-build, multilingual web experience that gives a voice to the **17 pioneering machines** NASA left behind on the Moon and Mars. Transforming raw telemetry and historical records from **NASA/JPL**, **NSSDCA**, and the **NASA Image and Video Library** into a gamified educational journey, the platform allows explorers to locate planetary relics on interactive maps, read first-person mission logbooks, test their STEM knowledge to earn XP, and unlock a downloadable **Space Explorer Certificate**.

## ✨ Key Features & Innovation

1. **Interactive Planetary Maps (Moon & Mars):** Explore landing sites and final resting coordinates of 17 iconic spacecraft, landers, and rovers.
2. **Humanized Telemetry & "Logbooks":** Dry engineering metrics—such as the *Opportunity* rover surviving **5,111 sols** against a **90-sol** design life—are translated into compelling, scientifically grounded narratives.
3. **Live NASA Image & Video Library Integration:** Online mode dynamically queries `images-api.nasa.gov` to display authentic mission photography with official NASA credits and source links, featuring automatic fallback to local illustrated assets when offline.
4. **Gamified Quizzes & XP Progression (14 Badges):** Users test their mission comprehension through interactive quizzes, earning Experience Points (XP) and unlocking **14 mission badges**.
5. **Custom Space Explorer Certificate:** Upon unlocking all 14 badges, the *Badges* panel generates a personalized certificate (editable name, rank, XP, date, and unique serial number) exportable as **PNG**, **PDF**, or print-ready format.
6. **Zero-Dependency Static Architecture:** Built purely with native **HTML5, CSS3, and Vanilla JavaScript (ES6+)**—requiring zero build steps, zero backend servers, and instant offline/local-first execution.

## 🧭 User Guide (How to Explore)

1. **Select Language:** Switch seamlessly between **English (`EN`)**, **Portuguese (`PT-BR`)**, and **Spanish (`ES`)** via the top navigation bar or URL parameters.
2. **Choose a Celestial Body:** Select **Moon** or **Mars** to inspect the orbital sector and surface coordinates.
3. **Inspect a Relic:** Click any of the **17 mission markers** on the interactive map to open its technical telemetry card, authentic NASA mission photo, and dramatized first-person *Logbook*.
4. **Complete Quizzes & Earn Badges:** Answer the telemetry challenges inside each artifact's logbook to accumulate XP and unlock badges.
5. **Claim Your Certificate:** Collect all **14 badges** and open the **Badges / Insígnias** panel to customize and download your official completion certificate.

## 🚀 Deployment & Configuration

### Local Execution (Zero Setup)
Simply clone or download the repository and open `index.html` directly in any modern web browser, or serve via any lightweight HTTP server:
```bash
python3 -m http.server 8080
```

### Web Hosting / Production (Apache / Nginx / GitHub Pages)
1. Upload all root files (`index.html`, `404.html`, `.htaccess`, `manifest.webmanifest`, `robots.txt`, `favicon.svg`) along with `css/`, `js/`, and `assets/` to your web root (e.g., `public_html/`). *(The `tools/` directory is for development only and can be omitted).*
2. Included `.htaccess` configures proper MIME types (`mp4`, `webm`, `webp`), Gzip compression, and browser caching. For Nginx, configure equivalent headers.

### URL Query Parameters & Customization
* **Language Override:** `?lang=en` | `?lang=pt` | `?lang=es` (Priority order: URL parameter $\rightarrow$ saved user preference $\rightarrow$ browser language $\rightarrow$ default).
* **Deep Linking:** Direct links to specific worlds or artifacts, e.g., `?lang=en#/a/apollo11` or `#/p/mars`.
* **Photo API Modes:**
  * `?photos=0` — Disable external NASA photo fetching.
  * `?photos=local` — Force local cached photography (`assets/img/photos/index.json`).
  * `EC.CFG.livePhotos = false` in `js/core/photos.js` — Globally toggle live API calls.
* **Adding a New Language:** Duplicate `js/i18n/ui.en.js` and `art.en.js`, register the locale in `EC.LANGS` (`js/core/i18n.js`), import the scripts in `index.html`, and validate with `node tools/check_i18n.js`.

## 📊 Data Sources & Methodological Transparency

* **Verified Mission Telemetry:** Launch dates, landing coordinates, mass, operational lifespan (sols/days), and engineering specifications were sourced from **NASA/JPL**, **NSSDCA**, and official NASA mission archives.
* **Dramatized Narratives:** First-person mission logbooks are creative educational dramatizations built around verified historical events.
* **Optional External Dependencies:** Google Fonts (with local system font fallback) and the **NASA Image and Video Library API** (`https://images-api.nasa.gov`).
* **Media Regeneration (Optional):** Developers can rebuild local media assets using Python 3 (`numpy`, `Pillow`, `opencv-python`, `ffmpeg`):
  ```bash
  python3 tools/gen_images.py && python3 tools/gen_maps.py && python3 tools/gen_video.py
  ```

**Ecos do Cosmos** (*Echoes in the Cosmos*) é uma experiência web interativa, multilíngue e sem necessidade de compilação (*zero-build*) que dá voz às **17 máquinas pioneiras** deixadas para trás pela NASA na Lua e em Marte. Transformando telemetria bruta e registros históricos da **NASA/JPL**, **NSSDCA** e da **NASA Image and Video Library** em uma jornada educacional gamificada, a plataforma permite explorar relíquias planetárias em mapas interativos, ler diários de bordo em primeira pessoa, testar conhecimentos STEM para ganhar XP e desbloquear um **Certificado de Explorador Espacial** personalizável.

## ✨ Principais Recursos e Inovação

1. **Mapas Planetários Interativos (Lua e Marte):** Explore os locais de pouso e as coordenadas finais de 17 sondas, módulos de pouso (*landers*) e *rovers* históricos.
2. **Telemetria Humanizada e "Diários de Bordo":** Métricas técnicas secas — como o rover *Opportunity* sobrevivendo por **5.111 sóis** frente a uma vida útil projetada de **90 sóis** — são transformadas em narrativas envolventes e cientificamente embasadas.
3. **Integração ao Vivo com a Biblioteca de Imagens da NASA:** No modo online, o site consulta dinamicamente a API `images-api.nasa.gov` para exibir fotografias reais das missões com créditos oficiais e links da NASA, contando com *fallback* automático para ilustrações locais quando offline.
4. **Quizzes Gamificados e Progressão de XP (14 Insígnias):** Os usuários testam seus conhecimentos através de desafios interativos, acumulando Pontos de Experiência (XP) e desbloquear **14 insígnias de missão**.
5. **Certificado Espacial Personalizado:** Ao conquistar todas as 14 insígnias, o painel *Insígnias* libera um certificado exclusivo (com nome editável, patente, XP, data e número de série único) pronto para baixar em **PNG**, **PDF** ou imprimir.
6. **Arquitetura Estática Sem Dependências:** Desenvolvido inteiramente em **HTML5, CSS3 e JavaScript puro (ES6+)** — sem etapas de *build*, sem servidor *backend* e com execução instantânea *local-first*.
